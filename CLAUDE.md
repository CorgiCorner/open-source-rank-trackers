# Claude guidance

Read and follow [AGENTS.md](AGENTS.md) before making changes.

## Commits

All commit messages and pull request titles must follow Conventional Commits:

```text
type(optional-scope): concise imperative description
```

Use an appropriate type such as `feat`, `fix`, `docs`, `chore`, `test`,
`refactor`, `ci`, `build`, `perf`, or `revert`. Keep the description lowercase
and specific. Do not use generic titles such as `Update project data`.
